# Modulo ML

La IA de riesgo conserva su registro demostrativo. El módulo de proyección de
rendimiento incluye un modelo numérico entrenado exclusivamente con datos
sintéticos en `backend/app/assets/performance-forecast-v1.json`.

El generador, entrenamiento, separación temporal y métricas se describen en
[predicción de rendimiento](../docs/ai/prediccion-rendimiento.md). El dataset
ficticio generado queda en `datasets/synthetic/performance-forecast-v1.json`,
excluido de Git. No contiene identificadores ni notas reales.
