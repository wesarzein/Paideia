# Estrategia de IA

1. Problema: clasificacion de riesgo academico.
2. Variable objetivo: presencia de potencial riesgo academico, definida pedagogicamente.
3. Features potenciales: rendimiento, asistencia, tendencia de notas, evaluaciones e historial disponible.
4. Datos historicos: necesarios para entrenar y validar.
5. Datos reales: se usaran solo con autorizacion, minimizacion y proteccion.
6. Datos sinteticos: permitidos para pruebas, identificados como sinteticos.
7. Entrenamiento: se definira tras conocer volumen y calidad de datos.
8. Validacion: separar entrenamiento, validacion y prueba.
9. Metricas: precision, recall, F1, matriz de confusion y calibracion.
10. Explicabilidad: priorizar interpretabilidad y variables comprensibles.
11. Limitaciones: sesgo, datos incompletos y cambios de contexto.
12. Uso: alerta temprana indicativa, no decision automatica.
