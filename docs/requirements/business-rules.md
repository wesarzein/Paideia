# Reglas de negocio

| ID | Regla |
| --- | --- |
| RN-01 | Solo usuarios autenticados acceden al sistema. |
| RN-02 | Todo acceso se controla por rol. |
| RN-03 | Las contrasenas nunca se almacenan en texto plano. |
| RN-04 | Los roles iniciales son ADMINISTRADOR, DOCENTE, COORDINADOR_ACADEMICO y PERSONAL_DIRECTIVO. |
| RN-05 | Los datos academicos deben asociarse a un periodo. |
| RN-06 | Un estudiante debe tener identificador interno unico. |
| RN-07 | Un curso debe tener codigo unico. |
| RN-08 | Una seccion pertenece a un grado. |
| RN-09 | Las calificaciones deben conservar historial cuando aplique. |
| RN-10 | El seguimiento academico no sustituye criterio pedagogico. |
| RN-11 | La IA solo genera alertas indicativas. |
| RN-12 | Las importaciones deben validar estructura antes de persistir. |
| RN-13 | Una importacion fatal debe revertirse completamente. |
| RN-14 | No se usan datos reales en ambientes de desarrollo versionados. |
| RN-15 | Los reportes deben respetar permisos. |
| RN-16 | Los KPIs deben derivarse de datos consistentes. |
| RN-17 | Toda modificacion critica debe ser auditable en fases posteriores. |
| RN-18 | Los formatos deben soportar espanol/Peru. |
| RN-19 | Los datos de menores requieren proteccion reforzada. |
| RN-20 | El alcance excluye funcionalidades de ERP institucional completo. |
